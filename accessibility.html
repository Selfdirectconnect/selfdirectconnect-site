Accessibility at SelfDirectConnect

Access Should Be Built In.

SelfDirectConnect is committed to creating an experience that people with disabilities can use with greater independence, including people who use screen readers, keyboards, screen magnification, voice tools, and other assistive technology.

Our Accessibility Commitment

Accessibility is part of how SelfDirectConnect is designed and developed. We are working toward conformance with the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA and will continue reviewing the platform as it grows.

Our goal is to make information, resources, forms, navigation, and professional connections understandable and usable by as many people as possible.

Accessibility Features

  • Semantic page structure and headings designed to support screen reader navigation.
  • Skip links that allow keyboard and screen reader users to move directly to main content.
  • Keyboard accessible navigation, links, buttons, forms, and menus.
  • Visible keyboard focus indicators.
  • Responsive layouts designed to reflow when text or the page is enlarged.
  • Support for browser zoom, screen magnification, and mobile pinch to zoom.
  • Color contrast designed to support readability.
  • Alternative text for meaningful images and hidden treatment for decorative graphics where appropriate.
  • Support for reduced motion preferences and high contrast or forced color modes.
  • Plain language and clear labels wherever practical.

Using Your Own Accessibility Tools

SelfDirectConnect is designed to work with accessibility features already available in browsers, operating systems, and assistive technologies. You can use your browser's zoom controls, screen magnification software, screen readers, keyboard navigation, or other accessibility settings without needing a separate accessibility widget.

We Are Continuing to Improve

Accessibility is an ongoing responsibility. As SelfDirectConnect adds new pages, forms, directory features, and services, we will continue testing and improving accessibility. We welcome feedback from people who use assistive technology and from anyone who encounters an accessibility barrier.

Need Accessibility Help?

If you have difficulty accessing information or using a feature on SelfDirectConnect, please contact us. Tell us which page or feature caused the problem and, if you are comfortable doing so, the assistive technology or browser you were using. We will use that information to help address the barrier.

Email: selfdirectconnect@outlook.com

SelfDirectConnect's accessibility work is ongoing. Stating that we are working toward WCAG 2.2 Level AA does not represent a certification or guarantee that every page or third party service is fully conformant at all times.
